Getting Started with Raspberry Pi

Prepare for your first Raspberry Pi project by learning about the basic hardware, software, and setup process.

What You Need

Raspberry Pi

Choose a Raspberry Pi model that matches your project goals and budget.

Storage

Use a compatible microSD card or other supported storage device for the operating system and files.

Power Supply

Use a reliable power supply that meets the requirements of your Raspberry Pi model.

Display and Input

A monitor, keyboard, and mouse make the initial setup easier for beginners.

Basic Setup Process

  1. Prepare your storage. Install a Raspberry Pi operating system on your microSD card or supported storage device.
  2. Connect your hardware. Connect your display, keyboard, mouse, and other required equipment.
  3. Power on the Raspberry Pi. Complete the initial operating system configuration.
  4. Update the system. Make sure the operating system and installed software are current before beginning a project.
  5. Choose your first project. Start with a beginner project that matches your interests and available equipment.
