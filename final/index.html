What Is a Raspberry Pi?

Raspberry Pi computers are small, affordable computers designed to make computing, programming, and electronics accessible to people of all experience levels.

Despite their small size, Raspberry Pi computers can be used for many practical and creative projects. You can learn programming, build a home server, experiment with electronics, automate devices, create media systems, and much more.

Raspberry Pi Project Hub is designed to help beginners understand the basics and discover projects they can start building.

What Can You Build?

Raspberry Pi computers can be used for projects ranging from simple beginner experiments to advanced home automation and networking systems.

Programming

Learn programming languages such as Python and JavaScript while creating practical applications.

Electronics

Connect LEDs, sensors, displays, and other electronic components using the Raspberry Pi GPIO pins.

Networking

Build home servers, network monitoring tools, private cloud systems, and other networking projects.
